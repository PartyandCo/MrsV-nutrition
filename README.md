# Διατροφικό Ημερολόγιο

Μια στατική εφαρμογή για την καταγραφή θερμίδων και μακροθρεπτικών (πρωτεΐνη, υδατάνθρακες, λίπος). Τα δεδομένα σου αποθηκεύονται τοπικά στον browser σου (`localStorage`) — δεν υπάρχει λογαριασμός ή βάση δεδομένων. Η μόνη εξαίρεση είναι η αναγνώριση γευμάτων με AI, που χρειάζεται μια μικρή serverless συνάρτηση (βλ. παρακάτω).

## Χαρακτηριστικά

- **«Πες μου τι έφαγες» (AI)**: γράφεις ελεύθερα τι έφαγες (π.χ. «2 αυγά τηγανητά και μια φέτα ψωμί») και ένα μοντέλο AI εκτιμά θερμίδες, πρωτεΐνη, υδατάνθρακες και λίπος — μπορείς να διορθώσεις τις τιμές πριν τις αποθηκεύσεις.
- **Ημέρα**: καταχώρηση γευμάτων (μέσω AI, γρήγορα από τη λίστα τροφίμων σου, ή χειροκίνητα), σύνοψη θερμίδων/μακροθρεπτικών με progress bars.
- **Τρόφιμα**: προσωπική βιβλιοθήκη τροφίμων που τρως συχνά, με θερμίδες/μακροθρεπτικά ανά μερίδα.
- **Ιστορικό**: γράφημα των τελευταίων 14 ημερών και πίνακας με τα ημερήσια σύνολα.
- **Στόχοι**: ορισμός ημερήσιου στόχου θερμίδων/μακροθρεπτικών, εξαγωγή/εισαγωγή δεδομένων (backup σε JSON) και διαγραφή δεδομένων.

## ⚠️ Σημαντικό για τα δεδομένα

Επειδή τα δεδομένα αποθηκεύονται μόνο στον browser της συσκευής σου:
- Αν καθαρίσεις τα δεδομένα browsing / cookies, θα χαθούν.
- Στο Safari/iOS συγκεκριμένα, αν περάσουν 7 μέρες χωρίς να ανοίξεις/πατήσεις κάτι στη σελίδα, το iOS μπορεί να διαγράψει μόνο του τα δεδομένα (πολιτική "Intelligent Tracking Prevention" — δεν σχετίζεται με αυτή την εφαρμογή, ισχύει για κάθε τέτοια σελίδα).
- Δεν συγχρονίζονται αυτόματα μεταξύ κινητού/υπολογιστή, εκτός αν ενεργοποιήσεις το «Αντίγραφο ασφαλείας στο cloud» παρακάτω.
- Κάνε τακτικά **Εξαγωγή δεδομένων (JSON)** από την καρτέλα «Στόχοι» για backup, και **Εισαγωγή** αν αλλάξεις συσκευή ή browser.

## Αντίγραφο ασφαλείας στο cloud (Netlify Blobs) — τι χρειάζεται

Στην καρτέλα «Στόχοι» υπάρχει η κάρτα «Αντίγραφο ασφαλείας στο cloud»: ορίζεις μια φορά ένα προσωπικό PIN, και από εκεί και πέρα κάθε αλλαγή στα δεδομένα σου αποθηκεύεται αυτόματα (με μικρή καθυστέρηση) σε ένα Netlify Blobs store — μια αποθήκευση δεδομένων που παρέχει το ίδιο το Netlify, ανεξάρτητη από κάθε deploy (δεν σβήνεται όταν ανεβάζεις νέα έκδοση του site). Υπάρχει και χειροκίνητο κουμπί «Επαναφορά από το cloud» για να φέρεις πίσω τα δεδομένα σε μια συσκευή (π.χ. μετά από απώλεια/καθάρισμα).

Χρησιμοποιεί τη συνάρτηση `netlify/functions/sync-data.mjs`, η οποία χρειάζεται το πακέτο `@netlify/blobs` (δηλωμένο στο `package.json` — το Netlify το εγκαθιστά αυτόματα σε κάθε deploy, δεν χρειάζεται καμία ενέργεια από σένα). Δεν χρειάζεται κανένα επιπλέον environment variable — το Netlify Blobs λειτουργεί αυτόματα μέσα σε Netlify Functions.

**Σημαντικό για το PIN**: δεν υπάρχει «ξέχασα το PIN» — αν το χάσεις, το συγκεκριμένο αντίγραφο δεν είναι προσβάσιμο (τα δεδομένα στη συσκευή σου δεν επηρεάζονται). Επίσης, όποιος μαντέψει/μάθει το PIN σου μπορεί να δει ή να αντικαταστήσει αυτό το αντίγραφο — δεν είναι πραγματικό σύστημα login, απλώς ένα κλειδί πρόσβασης. Διάλεξε κάτι όχι προφανές και μην το μοιραστείς.

## Η λειτουργία «Πες μου τι έφαγες» (AI) — τι χρειάζεται

Αυτή η λειτουργία καλεί μια μικρή serverless συνάρτηση (`netlify/functions/estimate-nutrition.mjs`) που με τη σειρά της καλεί το [Anthropic API](https://console.anthropic.com/) (Claude) για να εκτιμήσει τα διατροφικά στοιχεία. Για να δουλέψει, χρειάζεσαι:

1. **Έναν λογαριασμό στο https://console.anthropic.com/** και ένα API key (Settings → API Keys → Create Key). Θα χρειαστεί να προσθέσεις λίγο credit στον λογαριασμό (χρεώνεται ανά χρήση, βλ. «Κόστος» παρακάτω).
2. Στο Netlify dashboard του site σου: **Site configuration → Environment variables → Add a variable**.
   - Key: `ANTHROPIC_API_KEY`, Value: το κλειδί σου. Scope: όλα τα contexts.
3. Κάνε ένα νέο deploy (ή **Trigger deploy → Deploy site**) ώστε το Netlify να «δει» το νέο environment variable.

Προαιρετικά μπορείς επίσης να ορίσεις:
- `ANTHROPIC_MODEL` — αν θες να αλλάξεις το μοντέλο (προεπιλογή: `claude-haiku-4-5`, γρήγορο και φθηνό, κατάλληλο για αυτή τη δουλειά).
- `APP_SHARED_SECRET` — ένα δικό σου «μυστικό» string. Αν το ορίσεις, βάλε το ΙΔΙΟ string στη μεταβλητή `APP_SHARED_SECRET` στην κορυφή του `js/app.js`. Αυτό λειτουργεί ως ένα ελαφρύ φίλτρο ενάντια σε τυχαία bots/crawlers που μπορεί να βρουν το endpoint και να καταναλώσουν το credit σου — **δεν είναι πραγματική ασφάλεια**, αφού το string παραμένει ορατό σε όποιον ανοίξει τον κώδικα της σελίδας (devtools). Αν θες πραγματική προστασία, θα χρειαστεί κάποιο σύστημα login, το οποίο είναι μεγαλύτερη αλλαγή — πες μου αν το θες.

### Κόστος

Κάθε κλήση κοστίζει μερικά cents του δολαρίου (με το μοντέλο Haiku, τυπικά λιγότερο από $0.001 ανά γεύμα). Δεν υπάρχει μηνιαία συνδρομή — πληρώνεις μόνο ό,τι χρησιμοποιείς, από το credit που θα προσθέσεις στον λογαριασμό Anthropic. Αν θες, μπορείς να ορίσεις ένα μηνιαίο όριο δαπανών στο [Anthropic Console](https://console.anthropic.com/) (Settings → Billing → Usage limits) ώστε να μην ξεπεράσεις ένα συγκεκριμένο ποσό.

## Τοπική δοκιμή

Για τις καρτέλες Ημέρα/Τρόφιμα/Ιστορικό/Στόχοι δεν χρειάζεται τίποτα ιδιαίτερο — άνοιξε απλά το `index.html` σε browser, ή τρέξε έναν τοπικό server:

```bash
npx serve .
# ή
python3 -m http.server 8080
```

Η λειτουργία AI όμως χρειάζεται τη serverless συνάρτηση, που δεν τρέχει με τους παραπάνω απλούς servers. Για να τη δοκιμάσεις τοπικά, χρησιμοποίησε το Netlify CLI:

```bash
npm install -g netlify-cli
netlify dev
```

Αυτό θα σου ανοίξει την εφαρμογή σε localhost με ενεργή τη συνάρτηση. Θα χρειαστεί να έχεις ένα `.env` αρχείο στον φάκελο με `ANTHROPIC_API_KEY=το-κλειδί-σου` (μην το ανεβάσεις ποτέ σε δημόσιο GitHub repo — πρόσθεσε `.env` στο `.gitignore`).

## Deploy στο Netlify

> ⚠️ **Σημαντικό**: Το Netlify Drop (drag & drop στο app.netlify.com/drop) **δεν υποστηρίζει serverless functions** — άρα η λειτουργία AI δεν θα δουλέψει αν ανεβάσεις την εφαρμογή έτσι. Χρειάζεσαι είτε το Netlify CLI, είτε (καλύτερα) σύνδεση με GitHub.

### Επιλογή Α — Netlify CLI (χωρίς GitHub, αλλά με λειτουργικό AI)

1. Εγκατάστησε το CLI και συνδέσου:
   ```bash
   npm install -g netlify-cli
   netlify login
   ```
2. Μέσα στον φάκελο `nutrition-tracker`, κάνε το πρώτο deploy:
   ```bash
   netlify deploy --prod
   ```
   Θα σε ρωτήσει να συνδέσεις/δημιουργήσεις site — απάντησε στις ερωτήσεις (publish directory: `.`).
3. Πρόσθεσε το `ANTHROPIC_API_KEY` στο Netlify dashboard (βλ. ενότητα παραπάνω) και ξανατρέξε `netlify deploy --prod` ώστε να ενεργοποιηθεί.

Μειονέκτημα: κάθε φορά που αλλάζει ο κώδικας, θα ξανατρέχεις χειροκίνητα `netlify deploy --prod`.

### Επιλογή Β — Μέσω GitHub (συνιστάται — αυτόματο deploy σε κάθε αλλαγή, functions included)

1. Δημιούργησε ένα νέο repository στο GitHub και ανέβασε εκεί τον φάκελο `nutrition-tracker`:
   ```bash
   cd nutrition-tracker
   git init
   git add .
   git commit -m "Αρχικό commit"
   git branch -M main
   git remote add origin https://github.com/<username>/<repo>.git
   git push -u origin main
   ```
2. Πήγαινε στο https://app.netlify.com → **Add new site → Import an existing project**.
3. Σύνδεσε τον GitHub λογαριασμό σου και επίλεξε το repository.
4. Ρυθμίσεις build:
   - **Build command**: κενό (δεν χρειάζεται)
   - **Publish directory**: `.` (η ρίζα του φακέλου)
5. Πάτα **Deploy site**. Από εδώ και πέρα, κάθε `git push` θα κάνει αυτόματα νέο deploy — και θυμήσου να προσθέσεις το `ANTHROPIC_API_KEY` στα environment variables του site (βλ. παραπάνω) πριν δοκιμάσεις τη λειτουργία AI.

## Ιδέες για μελλοντικές επεκτάσεις

- Σύνδεση με πραγματική βάση δεδομένων (π.χ. Supabase) ώστε τα δεδομένα να συγχρονίζονται μεταξύ συσκευών, με login.
- Πραγματικό σύστημα login, ώστε το endpoint AI να προστατεύεται σωστά (όχι μόνο με το ελαφρύ shared-secret φίλτρο).
- Ενσωμάτωση δημόσιου API τροφίμων (π.χ. Open Food Facts) για αναζήτηση θερμίδων με barcode.
- Στόχοι βάρους και γράφημα προόδου βάρους.
- PWA (installable app) ώστε να λειτουργεί και offline σαν εφαρμογή κινητού.
